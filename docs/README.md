## Setting a priority

Marks how much a task matters, so that a long list still shows you what to do
first. A task has no priority until you give it one.

Format: `priority TASK_NUMBER LEVEL`

* `TASK_NUMBER` is the number the task shows in `list`, counting from 1.
* `LEVEL` is `high`, `medium`, `low`, or `none`. Capitalization doesn't matter,
  so `HIGH` and `High` both work.
* `none` takes a priority off again.

A task with a priority shows it in a box after its status box; a task without
one shows no box at all.

Example: `priority 2 high`

```
     Very good. I've set this task's priority:
       [T][ ][HIGH] submit report
```

Your priorities are saved with your tasks, so they're still there the next time
you start Alfred.

**Note:** `find` searches descriptions only, so `find high` looks for tasks with
the word "high" in them, not for tasks you've marked high priority.
